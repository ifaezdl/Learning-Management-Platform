# راهنمای نمودارهای داشبورد تحلیلی — مرجع ارائه

---

## 📊 بخش اول: داشبورد تحلیلی دانشجو

### ۱. تحلیل شکاف مهارتی (نمودار Radar)

**نوع نمودار:** Radar (عنکبوتی)

**کاربرد:** نمایش درصد تسلط دانشجو روی هر مهارت (برچسب سؤالات) به صورت بصری. مهارت‌های ضعیف سریعاً مشخص می‌شوند.

**فرمول و روش:**
- از تمام پاسخ‌های آزمون‌های ثبت‌شده دانشجو استفاده می‌شود
- پاسخ‌ها بر اساس `SkillTag` (برچسب مهارت) گروه‌بندی می‌شوند
- فرمول هر مهارت: **percentage = (تعداد پاسخ صحیح / کل پاسخ‌ها) × 100**
- مهارت‌ها از ضعیف‌ترین به قوی‌ترین مرتب می‌شوند
- هر نقطه روی نمودار = یک مهارت، فاصله مرکز تا نقطه = درصد تسلط

---

### ۲. روند پیشرفت در طول زمان (نمودار Line)

**نوع نمودار:** Line (خطی) — دو خط روی یک نمودار

**کاربرد:** نمایش تغییرات نمرات آزمون و درصد تکمیل دوره در طول زمان. مشخص می‌کند دانشجو رو به پیشرفت است یا افت.

**فرمول و روش:**
- **خط اول (نمره آزمون):** هر آزمون ثبت‌شده → محور X = تاریخ آزمون، محور Y = `(Score / MaxScore) × 100`
- **خط دوم (پیشرفت دوره):** با هر درس تکمیل‌شده → محور X = تاریخ تکمیل، محور Y = `(تعداد دروس تکمیل‌شده / کل دروس انتشار‌یافته) × 100`
- هر دو خط روی یک محور Z صفر تا ۱۰۰ رسم می‌شوند

---

### ۳. خلاصه مهارت‌های ضعیف (کارت هشدار)

**نوع:** کارت متنی با بج (Badge)

**کاربرد:** نمایش ۳ مهارتی که دانشجو کمتر از ۷۰٪ تسلط دارد و نیاز به مرور بیشتر دارند.

**فرمول:** فیلتر مهارت‌هایی با `percentage < 70` → نمایش ۳ تا اول (ضعیف‌ترین‌ها)

---

### ۴. کارت‌های خلاصه آماری (Stat Cards)

**نوع:** کارت عددی

| کارت | فرمول |
|------|-------|
| آزمون تکمیل‌شده | `تعداد کل آزمون‌های ثبت‌شده` |
| میانگین نمره آزمون | `Σ(نمره‌ها) / تعداد آزمون‌ها` |
| میانگین تسلط مهارتی | `Σ(درصدهای مهارت) / تعداد مهارت‌ها` |

## 📊 بخش دوم: داشبورد تحلیلی استاد (مدرس)

### ۵. پراکنش عملکرد دانشجویان (نمودار Scatter)

**نوع نمودار:** Scatter (پراکندگی)

**کاربرد:** نمایش هر دانشجو به صورت یک نقطه. محور X = پیشرفت دوره، محور Y = نمره آزمون. با یک نگاه مشخص می‌شود کدام دانشجوها عملکرد خوب/بد دارند.

**فرمول و روش:**
- هر نقطه = یک دانشجو که حداقل یک آزمون داده است
- محور X: `progressPercent = (درس‌های تکمیل‌شده / کل دروس) × 100`
- محور Y: `quizScorePercent = (مجموع نمرات / مجموع نمرات کل) × 100`
- دانشجویان بالا-راست = عملکرد خوب، پایین-چپ = عملکرد ضعیف

---

### ۶. میانگین تسلط مهارتی کلاس (نمودار Radar)

**نوع نمودار:** Radar (عنکبوتی)

**کاربرد:** نمایش میانگین تسلط کل کلاس روی هر مهارت. استاد می‌فهمد کدام مهارت‌ها نیاز به تدریس مجدد دارند.

**فرمول و روش:**
- پاسخ‌های **همه** دانشجویان دوره تجمیع می‌شود
- برای هر مهارت: `percentage = (مجموع پاسخ صحیح همه دانشجویان / مجموع کل پاسخ‌ها) × 100`
- هر نقطه = یک مهارت، میانگین کل کلاس رسم می‌شود

---

### ۷. لیست دانشجویان و تحلیل تفکیکی (جدول + Skill Bars)

**نوع:** جدول تعاملی با قابلیت باز شدن ردیف

**کاربرد:** جزئیات عملکرد هر دانشجو شامل: نمره آزمون، پیشرفت دوره، وضعیت قبول/مردود، روند یادگیری، و گواهینامه.

**ستون‌های اصلی:**
- **پیشرفت دوره:** نوار پیشرفت + نسبت `درس‌های تکمیل / کل دروس`
- **نمره آزمون:** `(Score / MaxScore) × 100` — رنگ‌بندی: ≥70% سبز، 40-70% زرد، <40% قرمز
- **روند یادگیری (TrendBadge):** بر اساس رگرسیون خطی (реgrssion) — بخش بعد را ببینید
- **وضعیت:** قبول/مردود بر اساس نمره آزمون نسبت به حد نصاب
- **مهارت‌ها (با باز شدن ردیف):** نوار پیشرفت جداگانه برای هر مهارت آن دانشجو

---

### ۸. روند یادگیری (TrendBadge)

**نوع:** بج رنگی + اسپارک‌لاین + مودال جزئیات

**کاربرد:** نمایش وضعیت روند یادگیری هر دانشجو: صعودی 🟢، نزولی 🔴، یا ثابت ⚪.

**فرمول و روش (رگرسیون خطی — Least Squares):**
- داده ورودی: نمرات آزمون‌ها مرتب بر اساس تاریخ
- x = شماره آزمون (0, 1, 2, …)، y = درصد نمره
- فرمول شیب: `m = (n × Σ(xy) − Σx × Σy) / (n × Σ(x²) − (Σx)²)`
- تصمیم‌گیری:
  - شیب > +2 → **صعودی** (پیشرفت)
  - شیب < -2 → **نزولی** (افت)
  - -2 ≤ شیب ≤ +2 → **ثابت**
- در مودال: نمودار خطی کامل نمرات + جدول جزئیات هر آزمون

### ۹. کارت‌های خلاصه آماری استاد (Stat Cards)

**نوع:** کارت عددی

| کارت | فرمول |
|------|-------|
| دانشجوی ثبت‌نامی | `تعداد کل انتساب‌ها (Enrollments)` |
| شرکت‌کننده در آزمون | `تعداد دانشجویانی که حداقل یک آزمون داده‌اند` |
| قبول‌شده | `تعداد دانشجویان با isPassed = true` |
| میانگین نمره | `Σ(نمره‌های درصدی دانشجویان شرکت‌کننده) / تعداد شرکت‌کنندگان` |
| میانگین پیشرفت | `Σ(پیشرفت درصدی همه دانشجویان) / تعداد کل دانشجویان` |

---

### ۱۰. ضعیف‌ترین مهارت‌های کلاس (کارت هشدار استاد)

**نوع:** کارت متنی با بج (مشابه بخش ۳ ولی در سطح کلاس)

**کاربرد:** نمایش ۳ مهارتی که میانگین تسلط کلاس کمتر از ۷۰٪ است.

**فرمول:** ابتدا تجمیع همه پاسخ‌ها → محاسبه درصد هر مهارت → فیلتر `percentage < 70` → نمایش ۳ تا ضعیف‌ترین
