## 1️⃣ تولید سوال با AI

### 🎯 هدف
خودکار تولید سوالات امتحانی بر اساس محتوای دوره

### 💻 فناوری
- **مدل**: Qwen3-4B (API-based)
- **ورودی**: محتوای دوره، اهداف یادگیری
- **خروجی**: آرایه JSON از سوالات تایید‌شده

### 🔑 کد کلیدی
```typescript
async generateQuestionsForCourse(course, count)
// → استخراج اطلاعات دوره
// → ساخت پرامپت ساختاری
// → فراخوانی Qwen AI
// → اعتبارسنجی کیفیت
// → برگرداندن سوالات
```

### ✅ فوایدها
- صرفه‌جویی ۱۰۰% در وقت مدرسین
- سوالات متنوع و معتبر
- برچسب‌های مهارت اتوماتیک

---

## 2️⃣ تحلیل مهارت‌ها

### 🎯 هدف
شناسایی مهارت‌های ضعیف دانشجو برای بهبود هدفمند

### 💻 فناوری
- **الگوریتم**: Grouping + Linear Regression
- **ورودی**: پاسخ‌های آزمون با برچسب مهارت
- **خروجی**: فهرست مهارت‌ها با درصد موفقیت و روند

### 🔑 کد کلیدی
```typescript
// 1. گروه‌بندی براساس برچسب مهارت
groupBySkill(answers) 
// → { tag, correct, total, percentage }

// 2. تشخیص روند (صعودی/نزولی/ثابت)
classifyTrend(scores)
// → محاسبه شیب رگرسیون خطی
// → slope > 2: صعودی
// → slope < -2: نزولی
```

### ✅ فوایدها
- درک جامع پیشرفت
- شناسایی نقاط ضعیف
- تشخیص خودکار نیاز به کمک

### 📊 نمونه خروجی
```json
{
  "skills": [
    { "tag": "مدیریت حافظه", "percentage": 40 },
    { "tag": "حلقه‌های تکرار", "percentage": 75 }
  ],
  "trend": {
    "status": "صعودی",
    "slope": 3.5
  }
}
```

## 3️⃣ توصیه‌گر هوشمند

### 🎯 هدف
پیشنهاد دوره‌های مناسب براساس پروفایل یادگیری

### 💻 فناوری
- **الگوریتم**: Weighted Scoring (4 عامل)
- **وزن‌ها**: 
  - مهارت ضعیف: 45%
  - سطح پیشرفت: 25%
  - علاقه قبلی: 20%
  - کیفیت دوره: 10%

### 🔑 کد کلیدی
```typescript
scoreCourse(profile, course)
// 1. محاسبه مطابقت مهارت (45%)
// 2. محاسبه سطح مناسب (25%)
// 3. محاسبه علاقه قبلی (20%)
// 4. محاسبه کیفیت (10%)
// → نمره نهایی: 0-100
```

### ✅ فوایدها
- توصیه‌های شخصی‌شده
- افزایش نسبت تکمیل دوره
- کاهش dropout rate

### 📊 نمونه خروجی
```json
{
  "courseId": 5,
  "title": "مدیریت حافظه پیشرفته",
  "score": 87,
  "matchedSkills": ["مدیریت حافظه"]
}
```

## 4️⃣ آزمون‌های پویا

### 🎯 هدف
معماری آزمون‌های منعطف و متعدد برای دوره

### 💻 ویژگی‌ها
```
┌──────────────────────────────────┐
│  دوره                           │
├──────────────────────────────────┤
│ ├─ آزمون ۱ (20 سوال)           │
│ ├─ آزمون ۲ (15 سوال)           │
│ └─ آزمون ۳ (تولید‌شده AI)     │
└──────────────────────────────────┘
```

### 🔑 عملیات کلیدی
```typescript
createQuiz()      // ایجاد آزمون جدید
updateQuiz()      // ویرایش تنظیمات/بانک سوالات
startQuiz()       // شروع آزمون توسط دانشجو
submitQuiz()      // ثبت پاسخ‌ها
deleteQuiz()      // حذف با حفاظت داده (soft delete)
```

### ✅ فوایدها
- انعطاف‌پذیری بیشتر
- حفاظت از داده‌های یادگیری
- آزمون‌های متعدد برای تقویت

---

## 5️⃣ چت Real-time

### 🎯 هدف
ارتباطات آنی و تعاملی در دوره

### 💻 فناوری
- **Protocol**: WebSocket
- **Library**: RxJS (Observable/Subject)
- **Features**: Reply, Reactions, Polls

### 🔑 عملیات کلیدی
```typescript
sendMessage()     // ارسال پیام
reactToMessage()  // واکنش emoji
createPoll()      // ایجاد نظرسنجی
votePoll()        // رای‌دادن
getMessageStream() // Subscribe به رویدادها
```

### ✅ فوایدها
- تعامل بلادرنگ
- نظرسنجی‌های زنده
- ارتباطات پویا
